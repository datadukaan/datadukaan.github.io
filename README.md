# Data Dukaan 🏪

100 days of data engineering system design, explained like a shop.
Site: **https://datadukaan.github.io** · Videos: Instagram & YouTube **@datadukaan**

- `docs/`: the website (MkDocs Material), one page per day
- `code/`: runnable examples for each day (PySpark, SQL, dbt) with sample data

Run locally: `pip install -r requirements.txt && mkdocs serve`
